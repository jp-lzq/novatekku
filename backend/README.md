# Backend

バックエンドのうち、公開できる共通部分をまとめたものです。

価格データを受け渡すための型、チャート計算、ログイン周りで使う小さな処理を置いています。`main.py` は公開内容を確認するための最小構成で、実際のサービスとは別です。

価格基準の更新では、商品と容量ごとの価格を一度スナップショットにまとめ、金額、取得時刻、必要な商品の不足を確認してから保存側へ渡します。途中までしか取得できなかった場合は、現在の基準値を残す設計です。

店舗との接続、データ保存、運用条件、管理機能は含めていません。

コードは閲覧と記録のために公開しています。利用、複製、改変、再配布はできません。詳しくはルートの `LICENSE` を確認してください。
