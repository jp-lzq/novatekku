# NOVA AI

NOVA AIは、iPhone買取市場の価格比較とスマートフォン相談を提供するデータ・AIサービスです。大量の価格情報を整理し、わかりやすい判断材料として届けます。

## 公開サイト

- NOVA AI: **https://ai.novatekku.com**
- AI回答テスト: **https://ai.novatekku.com/test**
- 会社サイト: **https://novatekku.com**
- GitHub: **https://github.com/jp-lzq/novatekku**

## 主な機能

- iPhone買取価格の店舗別比較
- 機種・容量・カラー別の査定
- 価格履歴とKラインチャート
- NOVA AIによる価格分析とスマートフォン相談
- 日本語 / English / 中文 の3言語対応
- 店舗情報、公式サイト、買取導線の案内

## データ概要

| 項目 | データ量 |
|------|----------|
| 最新価格データ | 1,000万件以上 |
| 価格履歴データ | 5,000万件以上（2020年〜2025年） |
