# バックエンド公開部分について

実際のバックエンドは、外部との接続、アプリ側の処理、データ保存を分けています。今回公開しているのは、その境界になる型と、単独で確認できる共通計算です。

```text
application
  ├─ data source
  ├─ analysis
  └─ repository
       └─ pricing utilities
```

チャート用の移動平均や RSI、値のばらつきを見る処理、パスワードとレート制限の基礎部分が入っています。FastAPI は死活確認だけの小さな構成です。

価格の基準値を更新する時は、取得、検証、保存を分けています。公開部分には、商品と容量ごとの価格を一つのスナップショットとして確認する処理を追加しました。金額、取得時刻、必要な商品の不足を先に検査し、途中までしか取れなかったデータは保存側へ渡しません。保存処理は、検証済みのスナップショットをまとめて置き換える前提です。

外部サービスごとの接続方法、運用上の判断、保存先、権限管理はここには置いていません。公開用の `main.py` と Dockerfile も、この構成を確認するために別で用意したものです。

公開対象はファイル単位で決めています。新しいファイルは分類が済むまで公開側へ入りません。接続先や認証情報などが混ざっていないかも、書き出す時に確認します。

利用条件はルートの `LICENSE` にまとめています。
