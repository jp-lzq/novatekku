# NOVA 構成

NOVA は 4 つのシステムで構成されています。このリポジトリには **Web サイト・データベース・AI ゲートウェイ** が含まれます。
価格収集システムと AI コアは別リポジトリ（非公開）です。

```
 価格収集（非公開） ──書き込み──▶  データベース  ◀──読み取り── Web サイト
                                      ▲
                                      └──読み取り── AI ゲートウェイ ──▶ AI コア（非公開）
```

| システム | 場所 | データベース権限 |
|---|---|---|
| Web サイト | `frontend/`, `backend/app/web/`, `backend/app/pricing/` | 価格は読み取りのみ。会員データと AI 会話ログのみ書き込み |
| データベース | `backend/app/db/`（テーブル定義・移行・権限） | 所有者アカウントで移行を実行 |
| AI ゲートウェイ | `backend/app/ai_gateway/`（API・利用回数・質問の前処理） | Web サイトと同じアカウント |
| 価格収集 | 非公開リポジトリ | 価格・商品・収集記録のみ読み書き。会員データは読めない |
| AI コア | 非公開リポジトリ（`answer(request) -> str` を提供） | データベースに接続しない |

## backend/app

- `db/` — `models.py`（全テーブル）、`roles.py`（システムごとの権限）、`migrate.py`（テーブル作成・価格インデックス再構築・権限付与）
- `pricing/` — 市場平均、コンセンサス価格、日次高値、標準商品カタログなどの価格計算
- `web/` — Web サイト API（価格、商品、店舗、会員、管理画面）
- `ai_gateway/` — `/api/v1/ai/*`。`preprocess.py` が言語・機種・容量・台数を判定して価格データを選び、`core.py` の `AIRequest` を AI コアへ渡す
- `api.py` — ルーターを `/api/v1` にまとめる

## 収集元

収集元の URL はコードに含めず、`collection_sources` テーブルで管理します。
管理者は管理画面から収集記録を確認できますが、一般公開 API は収集元 URL を返しません。

## AI コアの差し替え

`AI_CORE_MODULE` に `answer(request: AIRequest) -> str` を持つ Python パッケージ名を指定します。
未設定・未インストールの場合、AI は「一時的に利用できません」と応答します。
