# NOVA AI プラグイン

単独で使える AI ツールです。どれも標準ライブラリのみで動き、OpenAI 互換の API（`AI_API_URL` / `AI_API_KEY` / `AI_MODEL`）に接続します。
AI の出力はそのまま使わず、必ずプログラム側で検証します。

| プラグイン | 内容 | AI の出力の扱い |
|---|---|---|
| [ai-quote-parser](ai-quote-parser/) | 自由形式の見積もり文を、機種・容量・台数・単価の行データに変換 | 元の文章にない金額や実在しない機種は除外 |
| [ai-answer-judge](ai-answer-judge/) | AI 回答をルール検査と AI 採点で評価し、合格率を集計 | 言語・表形式などのルール検査が優先 |
| [ai-price-anomaly](ai-price-anomaly/) | ほかの店舗と大きく離れた価格を検出し、原因を推定 | 検出は統計のみ。AI は決められた原因から選ぶだけ |
| [ai-intent-router](ai-intent-router/) | 質問を 9 種類の目的に分類 | 不明なラベル・低い確信度は規則で判定し直す |

## 処理速度（AI 呼び出しを除くローカル処理）

| 処理 | 件数 | 時間 |
|---|---|---|
| 価格の外れ値検出 | 25,000 件 | 約 0.02 秒 |
| 質問の規則分類 | 3,000 件 | 約 0.1 秒 |
| 見積もり金額の照合 | 3,000 行 | 約 0.05 秒 |
| 回答のルール検査 | 3,000 件 | 約 0.3 秒 |

AI 呼び出しは 20〜25 件ずつまとめて送るため、件数が増えてもリクエスト数は少なく抑えられます。

## テスト

各ディレクトリで `python -m unittest`。テストは偽の AI クライアントを使い、外部 API には接続しません。CI で全プラグインを実行しています。
